# 💎 GEM Coin (A3Z Edition)

**GEM Coin** is a decentralized, peer-to-peer cryptocurrency built on Python, inspired by the fundamental principles of **Bitcoin (BTC)**.

## 🚀 Key Features
* **Decentralized Network:** Independent digital asset.
* **Proof-of-Work (PoW):** Secured by mining.
* **Owner/Developer Reward:** A fixed **5% Founder's Reward** is automatically routed to the project's official wallet address for every block successfully mined.
